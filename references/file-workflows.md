# 文件任务：减少返工

- 局部修改先映射“指定页/章节—修改要求—证据—输出位置”，复用已提取素材。只读必要上下文，不擅自全稿重做。
- 使用已有稳定样式与构建工具；若需新模板，优先验证最密集的一页。按真实字体、中英文宽度、换行和段间距预留空间，不要先创建大量偏小文字框再统一补救。
- 页面正文承载结论、关键数值和证据状态；冗长方法可放备注，但不能移走影响结论成立的条件。图片与数据必须有来源，不用虚构内容填版面。
- 先做结构、顺序与溢出检查，再逐页视觉复核。检查字号可读性、照片比例、标题间距和卡片内边距；自动通过不等于视觉通过。
- 修复后只重渲染变化页及依赖项，保留其他页的检查结果。反复修复同类问题时修正模板规则，而非逐个堆补丁。
- 用户只要修改部分时，仅交付指定页面；中间脚本、日志和预览留在工作目录。
